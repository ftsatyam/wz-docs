# Mirror & Leech Commands Reference

| Command | Alias | What it does |
|---|---|---|
| `/mirror [link]` | `/m` | Download with Aria2, upload to cloud |
| `/qbmirror [magnet/torrent]` | `/qm` | Download torrent with qBittorrent |
| `/jdmirror [link]` | `/jm` | Download with JDownloader (premium hosters) |
| `/nzbmirror [link]` | `/nm` | Download with SABnzbd (Usenet) |
| `/ytdl [link]` | `/y` | Download with yt-dlp (YouTube, social media, streams) |
| `/leech [link]` | `/l` | Download with Aria2, send to Telegram |
| `/qbleech [magnet/torrent]` | `/ql` | Torrent download, send to Telegram |
| `/jdleech [link]` | `/jl` | JDownloader download, send to Telegram |
| `/nzbleech [link]` | `/nl` | SABnzbd download, send to Telegram |
| `/ytdlleech [link]` | `/yl` | yt-dlp download, send to Telegram |
| `/uphoster [file]` | `/up` | Upload a file to DDL hosting sites |
| `/clone [link]` | `/cl` | Copy files/folders between Google Drives |

**Arguments** — see the [Arguments Reference](/reference/commands/arguments).
