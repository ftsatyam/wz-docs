# wz-docs

Documentation for [HKML-X](https://github.com/Imkrishana/HKML-X) — a Telegram mirror and leech bot.

Built with [VitePress](https://vitepress.dev/).

## Local dev

```bash
npm install
npm run docs:dev
```

## Build

```bash
npm run docs:build
```

Preview with `npm run docs:preview`.
